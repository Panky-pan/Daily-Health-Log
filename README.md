# Daily-Health-Log ·「每日健康打卡」

> 一个只服务自己的极简健康打卡网页：每天花 1 分钟记录运动、饮食、体重和饮水，坚持情况一屏看清，目标没达成时页面内提醒。

## 这是什么

市面上的健康 App 大多为「泛人群」设计，功能重、广告多、数据在别人服务器上。这个项目走相反的路：**轻量、无账号、无广告、数据只存在自己的浏览器里**，只做四件事——记录、坚持、趋势、目标提醒。

项目从零基础起步，按 28 天计划一天一小步推进，边做边学。

## 计划中的功能（MVP）

| 编号 | 功能 | 一句话说明 |
|---|---|---|
| F1 | 目标设置 | 首次打开填「每日运动分钟数」「每日饮水量」，之后可随时改 |
| F2 | 今日打卡 | 运动类型 + 时长、三餐（一句话 + 清爽/标准/丰盛标签）、体重、饮水；卡路里自动估算，不手填 |
| F3 | 打卡日历与坚持率 | 当月日历标记打卡日，显示当前 streak、历史最长连续天数、当月坚持率，可点开单日详情 |
| F4 | 趋势图表 | 体重折线图 + 每周运动时长柱状图 |
| F5 | 目标提醒条 | 页内黄色提醒条写清差多少，达标变绿，不弹窗不推送 |

页面结构：① 今日打卡页（首页）② 历史记录页 ③ 趋势页 + 一个设置区。

## 技术方案

**路线 A：现行 MVP（纯前端）**

- 原生 HTML + CSS + JavaScript，不用任何框架
- 数据存浏览器 `localStorage`（key 以 `dhl:` 前缀隔离）
- 部署到 GitHub Pages，双击 `index.html` 也能直接打开使用
- 无账号、无服务器、无后端

**路线 B：二期蓝图（账号 + 云端同步，仅设计未动工）**

- React + Vite 前端，腾讯云 CloudBase 云函数，PostgreSQL 数据库，静态网站托管
- 启动条件：MVP 上线且本人连续使用满 1 个月
- 现有数据结构已按云端字段名对齐，将来迁移不做返工

技术选型的完整对比与取舍理由见 `TECH_DESIGN.md`。

## 数据与隐私

- 所有打卡数据只写入浏览器的 `localStorage`，不上传任何服务器
- 无账号、无注册、无第三方统计与追踪
- 附带风险（已写入产品文档）：清理浏览器数据、换浏览器或换设备会丢数据，UI 里会明确提示
- 仓库内不含任何密钥：`.env`、`*.pem`、`*.key`、本地数据库文件已通过 `.gitignore` 全部排除

## 明确不做

食物数据库 / 拍照识餐、社区与分享、智能训练计划、饮食推荐、消息推送、会员付费、广告，以及 MVP 阶段的任何账号体系。

## 开发说明

- 本地查看：直接用浏览器打开 `index.html`（纯静态，无需安装任何依赖）
- 提交规范：提交信息格式为 `Day X｜一句话说明`，说明两行写明「改了什么 / 加了什么」
- 协作方式：与 AI 按 `AGENTS.md` 约定的规则推进——一次只做一步、先计划后确认、每步给出可亲眼验证的结果
